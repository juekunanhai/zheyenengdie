# 结束页与游戏背景修复 R11

用户已明确要求完成结束 UI 修复，并认真还原原 UI 中的游戏背景；基础难度已认可。

最小方案：保留 Result 独立场景，重排真实高度与重开，复用已认可首页底景/角色，补独立标题贴纸、关闭按钮和少量装饰。游戏只替换必要背景，并在现有 HeightBackdrop 增加独立飘云；保留高度阈值、同一镜头位移及物理尺寸。

是否需要更复杂方案：不需要。现有场景、Sprite、UIOpacity、动态 Label 和高度表现组件足以承载；不开发跨场景塔截图、额外成绩系统、通用弹窗框架或新的背景引擎。

依据：原 02_ui_design_system 的第 2 结算屏与第 6 背景小图、05_hud_reference 的城市/云层/近太空画法；功能仍以最新 SPEC 和用户确认规则为准。历史图片仅作审查，不抠图进正式素材。所有生成只发送纯文字描述，不上传本地输入。

玩法源码与物体数据不变；短屏、长屏和宽屏验证实际 Result/HUD。正常游戏高度变化与静态指定高度预览分别记录。真实高度、重开、关闭、飘云及返回 Home 需实际引擎验证。

最后自查修订：重试按钮改为红三角黄胶囊；为了消除3–12m同源楼群重影，HUD将城市作为同速远景，新增独立透明地面前景与塔同速。仅表现层增加Sprite，不增加物理状态。最终8项导入为4张替换与4张新增，67张运行PNG。
