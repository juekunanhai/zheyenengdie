# R8 首页专项修正

审阅入口：[R8 首页](index.html)。本轮仅制作独立首页审阅稿，未修改 Cocos、R7、物理尺度或玩法功能。

## 已确认的方向

用户指出 R7 物品质感可以保留，但首页背景与原 UI 的风格不搭。随后明确：更有趣不等于统一卡通化，各种风格的物品可以共存。统一的是呈现质量、清晰度与接触可信度，保留不同物品的材质和性格。

用户确认的最小修正范围为首页背景与整体构图。本轮采用一张新背景，复用正式 Logo、设置与开始按钮、平台、纸箱、冰箱、篮球，以及 R7 的独立云。无需引入新的玩法状态、物品系统或通用渲染框架。

## 本轮变化

| 项目 | R7 | R8 |
| --- | --- | --- |
| 背景方向 | 规整街道、大片铺地、安静陈列感 | 蓝／黄／珊瑚色城市错落向上，弱化道路透视 |
| 主体构图 | 展示塔体量较小、近乎同轴 | 主体整体等比放大，横向轻微错位，保留接触关系 |
| 物品 | 现有正式物品 | 保留原图与材质，没有全部重画、拟人或圆润化 |
| 文字和操作 | 正式 Logo、文案与按钮 | 保留并重排；平台与开始按钮分开 |
| 动态 | 独立云漂移 | 沿用独立云，静帧也依靠建筑和主体构图形成层次 |

背景在首页中采用固定的底部取景和 135% 显示比例，使地面与平台脚底衔接。它是首页美术取景，不是游戏镜头逻辑，不应直接复制为随高度变化的玩法背景。

## 检查与边界

- 已在 Codex 内置浏览器检查 375 × 667 与 375 × 812 首页构图；Logo、物品、平台、文案和按钮没有相互遮挡。
- R8、R7 首页截图、原 UI 整图三个模式均可切换，参考图片加载正常。
- 两次云 transform 读数均变化，背景显示矩形不变；暂停后 animation-play-state 为 paused。按钮仅预览按压，不进入玩法或修改设置。
- 已显示的场景图片无加载失败，JS 语法检查通过。
- 截图记录：[短屏](evidence/home-667.png)、[长屏上部](evidence/home-812-upper.png)、[长屏下部](evidence/home-812-lower.png)。
- 这不是游戏运行结果，没有运行物理、音频或 Cocos 构建。减少动态效果与前后台处理保留在小样代码中，本轮未模拟系统偏好或验证微信真机。
- 原 UI 的趣味还来自更多异质物品及其组合；本轮保留当前三种物品，未擅自扩充物品池。整体风格方向仍待用户审阅。
