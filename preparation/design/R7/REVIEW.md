# R7 基础视觉与动效审阅说明

本轮在已确认的 R6 布局上精修材质、接触关系和动作表现。短抓手、顶部高度牌、左侧三星、竖排道具区，以及物体直接叠放、不添加装饰木板隔层，继续沿用已确认方向。

审阅入口：[独立视觉小样](index.html)。本轮没有将候选图接入 Cocos，没有修改物理规则，也没有继续 Batch 1B。用户此次审核的是 **R7 整体视觉与动效方向**；审核通过后，再确认 Cocos 正式接入范围。

## 为什么做这一轮

目前工程具备基础交互与物理链路，但视觉上存在各元素光照方向不同、物体接触暗部不足、面板留白与当前信息量不匹配、按钮缺少触感，以及环境过于静止的问题。单个素材的体积不能自动形成整套画面的质感。

本轮的目标是让已有蓝黄玩具世界在材质、比例、接触和动作上更一致。质感不靠额外堆积图标、粒子或装饰；每个元素应有合理的明暗、边缘、空间关系和反馈。

## 最小方案与复杂度判断

**最小方案：**复用合格的正式物体、按钮、抓手和挂牌，仅补足四类不足的图片；背景使用一张无云地面底图与最多三朵独立云，配合小范围接触软影、统一文字层级和短促操作过渡。

现阶段无需引入新的游戏状态框架、通用动效系统或渲染层架构。当前明确需求只是统一已有画面和少量环境动作，现有呈现职责足以承载；建立更复杂的结构不能直接解决材质和构图问题。

本页 HTML 只是独立审阅载体，不是下一版运行时架构。已有正式素材的物理尺寸来源仍是既定玩法尺度，不用新图片的像素大小决定碰撞尺寸。

## 六种状态与工程对照

| 状态 | 当前工程对照重点 | R7 精修方向 |
| --- | --- | --- |
| 首页 | 展示塔、平台和开始按钮之间的关系较拥挤 | 保留正式主体，让承台与按钮分开，补接触与地面软影，背景云缓慢漂移 |
| 地面开局 | 背景静止，竖槽由横图旋转，提示和控件质感不统一 | 以地面为起点，采用正向光照的竖槽，降低空槽存在感，保留中央操作空间 |
| 已有堆叠 | 物体主要靠各自图片表达体积，接触处联系较弱 | 用小范围接触暗部连接纸箱、冰箱和篮球，不额外插入木板 |
| 暂停 | 暂停反馈不明确，可能仍见释放提示 | 明确“已暂停”，压暗后景，冻结环境动作，突出继续入口 |
| 设置 | 面板较空，文字层级与功能可用状态不够清楚 | 紧凑面板与统一文字关系；未接入项诚实标明，仅演示已有项的界面状态 |
| 结算 | 删去未实现信息后，剩余内容未重新收拢 | 以高度和重开为中心，不预留大块空洞，不增加未实现奖励或死因 |

“当前工程”使用 [before/](before/) 下保留的截图；其中“已有堆叠”来自暂停时的堆叠截图，不能把它解释成新的可运行状态。工程截图为 375 × 667；切换到长屏时保留其原比例，不宣称它是长屏工程实测。

R7 中塔的位置是静态摆放，**4.1 m 为构图示例，不是物理运行成绩**。页面里的开始、继续和重开只是切换示意状态；旋转按钮只展示转动过渡，不释放物体，不计算碰撞。设置开关只影响当前 HTML 小样，不修改游戏偏好，也不代表声音或震动功能已接入。

## 环境与操作动作

- 独立云有不同的速度、大小、透明度和轻微浮动，放在后景；不让云层遮挡当前物体、NEXT、高度或关键操作。
- 地面和城市不随时间自行漂移。正式工程中的地面与背景仍应随镜头高度产生相应的移动和视差，不能把小样的静态构图直接复制成固定背景。
- 按钮有按压反馈，旋转有短促的角度过渡；动作负责表达操作发生，不承担物理演算。
- 暂停时停止环境动作；离开前台和系统要求减少动态效果时也应停下或简化环境动作。
- 本轮只审 **地面阶段的画面及独立云层**。后续背景仍按当前镜头高度切换阶段；云层高空与太空等全部高度背景尚未完成这一轮运行画面验收，不能据此宣称已完成全高度背景。

## 后续接入优先级

1. 先锁定本次六状态的材质、布局与文字关系，确认新图方向；记录需要调整的具体画面。
2. 获准接入后先处理候选资源导入、透明边缘与显示比例，并统一竖槽、面板、文字与暂停显示。
3. 再接按钮反馈、旋转过渡和基于真实接触的小范围暗部；不得用静态示意影子冒充运行中的接触判断。
4. 最后接独立云与镜头高度／阶段逻辑，检查暂停恢复、前后台、短长屏，以及背景运动不干扰操作。
5. 用相同六状态在 Cocos 运行画面中回看。独立 HTML 的通过不能替代引擎资源、物理、性能或微信真机验收。
