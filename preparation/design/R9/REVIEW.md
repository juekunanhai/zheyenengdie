# R9：按原 UI 首页主视觉修正

[审阅页](index.html)。仅首页独立视觉稿，未修改 Cocos、正式物理参数、玩法物品池或已有 R7/R8 文件。

## 本轮纠正

用户明确指出原首页的主体是带眼睛的蓝箱、表情马桶、黄鸭和带眼睛的红拖鞋，配卡通城市、文字木牌。R7/R8 错把首批玩法使用的纸箱、冰箱、篮球继续当作首页主角，只改背景，未还原原 UI 的核心组合。

本轮直接按该组合制作首页。更有趣不等于把所有游戏物品统一卡通化；本页拟人表情属于用户明确指定的首页主视觉，其他物品仍允许风格差异。

## 最小方案

复用正式 Logo、开始／设置按钮和已清理的红色表情拖鞋。缺失的蓝色表情箱、表情马桶与黄鸭合为一张首页装饰插画；另补城市背景和空白木牌，木牌文字独立排版。无需引入新的游戏状态、碰撞体或物品系统。

- 下至上：蓝箱 → 白色表情马桶 → 黄鸭 → 一双红拖鞋。
- 木牌文案：平凡的东西／也能创造／不平凡的高度！
- 原标语：把乱七八糟的东西叠上天。
- 原图的等级、金币、今日挑战等已排除功能不恢复。
- 不从历史展板抠取正式素材。参考模式显示原图作为对照，图内历史功能不覆盖产品规则。
