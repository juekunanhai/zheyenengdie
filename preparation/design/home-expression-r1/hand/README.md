# 首页调皮小手

两张正式透明 Sprite 由内置 image_gen 生成，以 `home_r9_hero.png` 的白色马桶玩具材质为参考。只新增手臂和手掌叠加层，原主角不重绘。`prompts.json` 保存完整提示词，`generated_*.png` 保存生成源文件，`process.py` 保存本地透明化与缩图过程。

- 运行时：`assets/batch0/art/home_arm_open_r1.png`、`home_arm_grip_r1.png`，含 Cocos meta。
- 两帧均为 291×276 RGBA；原 hero 为 1024×1536。
- 原图肩部枢轴 `(424, 801)`，Sprite 内肩枢轴 `(249.9, 39.9)`，均以左上为原点。
- Sprite 左上放在 hero 的 `(174, 761)`，握住接触点约 `(262, 992)`，即箱子左前盖沿。
- 运行时用固定肩部枢轴旋转，张手可从 Cocos `-12°` 的抬手姿态进入 `0°` 握住姿态；只移动手臂，不让箱子和马桶分散漂移。
- `hero_open_composite.png` 和 `hero_grip_composite.png` 已在原始主角上合成并目视验收；没有棋盘底、绿色底、重复主角或背景补丁。

生成的张手源图带烘焙棋盘底，握手源图使用绿色蒙版底。两者已在本地按白色玩具主体提取透明轮廓并以最终显示尺寸抗锯齿，保持已有像素质感。单独重做张手背景的生成请求被工具审核拒绝，未重试；最终张手资产使用已经成功生成的第一张源图。
