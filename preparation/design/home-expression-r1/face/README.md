# 首页表情帧 R1

使用内置 image_gen 编辑原首页英雄与拖鞋图，提取 4 个眼部补片。默认睁眼/笑眼状态继续使用现有原图，补片仅在眨眼或调皮凝视时短暂显示。没有更换主体造型、重新摆放堆叠关系或绘制网页占位图。

- 鸭子：双眼开心闭合。
- 蓝箱：当前睁开的左眼闭合，原有右侧眨眼保留。
- 马桶：原有笑眼短暂睁开，随后恢复笑眼。
- 拖鞋：双眼开心闭合，嘴巴保留原位置。

精确坐标及 SpriteFrame UUID 见 `manifest.json`。矩形坐标从原图左上角计，尺寸是源像素尺寸；运行时按原图实际显示比例定位，禁止把此坐标用作物理几何。补片均为 RGBA，已带 Cocos `.meta`，不要裁切透明边距。

`finished-review.png` 为原图及表情覆盖明暗底检查，`patch-detail-review.png` 为局部放大。`VALIDATION.json` 验证原文件未修改、轮廓及透明像素完全保留、补片尺寸/元数据一致。注意原素材内部 alpha 多为 252–253；眼部补片在内部变为不透明以完整盖住原眼睛，不能宣称所有内部 alpha 完全不变。

生成全图未提供可靠透明背景，因此只保存在本设计目录供追溯，不能将其用作游戏主图。`hero-prompt.txt`、`slipper-prompt.txt` 为实际提示词；`PROVENANCE.json` 包含来源与哈希；`process_faces.py` 可用保存的本地源图重建补片。

本子任务只交付美术帧及证据，没有修改代码、场景或运行构建。动态时序及引擎视觉验收由主任务负责。
