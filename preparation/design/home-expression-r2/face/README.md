# 首页眼部动作小样 R2

仅供独立动作小样审核，不导入生产美术目录、Home.scene 或引擎工程。两位角色均沿用原首页主图；原画的马桶笑眼不变。

## 交付格式

- 鸭子：`duck_00.png` 至 `duck_06.png`，源矩形 `(334, 61, 173, 114)`。
- 箱子：`crate_00.png` 至 `crate_06.png`，源矩形 `(284, 1089, 148, 174)`。
- 坐标从原图左上角计算，原图大小 `1024 × 1536`。
- 7 帧闭合进度依次为 0、16.667、33.333、50、66.667、83.333、100%。
- 所有帧都是同尺寸 RGBA 补片。**帧 0 全透明**，让底图原来的眼睛精确呈现；其他帧只覆盖实际眼睑遮挡区域，不复制整块脸，也不做双眼交叉淡化。
- 原眼球、瞳孔、高光均不缩放、不位移。被眼睑遮住之前仍直接显示原图的对应像素。

详细路径、尺寸、帧哈希见 `manifest.json`。替换当前补片即可，不应把 7 帧叠加起来。反向使用相同帧可睁开。

## 动作含义与时间

鸭子做一次自然眨眼：上眼睑先盖下，稍有下眼睑配合。箱子只用帧 0→1→2→1→0，浅眯阶段以下眼睑抬起为主，上眼睑与瞳孔高光保持原样。箱子不使用 50% 以上帧做当前浅眯表演。

动作小样播放器统一控制时序，最终采用鸭子闭合 70ms／停留 35ms／睁开 120ms，箱子回应闭合 80ms／停留 80ms／睁开 150ms，并在手接触后发生。manifest 的 suggested 字段仅是素材初始建议，不是产品配置；以整页动作播放器为准。

`duck-mobile-1x.gif`、`crate-mobile-1x.gif` 将主角显示为 235px 宽，近似 375px 宽首页里的实际物理像素尺寸。`*-detail-3x.gif` 和 `*-filmstrip.png` 供放大检查。GIF 的短帧时间可能被查看器取整或延长，最终节奏应审核整页播放器的正常与 0.5 倍录像。

## 素材处理

内置 image_gen 生成闭眼薄褶皱参考。但初次生成附带的凸起眼罩、高光和亮环未用于最终补片。最终以原脸周边的黄色／蓝色渐变补回遮挡区域，只保留生成褶皱的颜色和测得的局部轨迹。这样避免在脸上增加一块新球形眼皮。

原嘴与眉需要独立保护。鸭左眼边缘与嘴沿紧邻，最终使用原图嘴沿源坐标保护遮罩，避免把黄色补进鸭嘴；`source-beak-landmarks.png` 记录定位参考，`beak-boundary-check.png` 给出原图与闭眼的 4 倍局部对照。该标记只是保护遮罩，不是新画嘴部。

`VALIDATION.json` 记录原生产主图未改、帧 0 透明、尺寸一致、覆盖面积单调、原轮廓透明像素未被触碰、眉／嘴保护区零触碰、箱浅眯高光保持原样。正常尺寸与局部材质已由独立审查确认可进入整页动态小样；完整手眼时序由主任务继续验收。

`prompt.txt` 为内置生成提示词；`original-hero.png` 和 `generated-closed-lids.png` 保存原始来源；`make_blink_frames.py` 可以重建候选。所有工作均保留在本 R2/face 目录内。
