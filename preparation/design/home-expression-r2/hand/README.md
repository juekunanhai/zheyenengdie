# 首页小手 R2 独立动作小样

此目录仅用于审核，未改生产素材、场景或运行时代码。

`manifest.json` 约定 24fps、49 帧、2 秒完整表演。每帧 330×376，叠加在原 1024×1536 hero 的 `[150,680,480,1056]` 区域。播放器直接按帧绘制，不额外旋转整条手臂或改变透明度。`hand_atlas.png` 为 7×7 帧图集，`frames/` 保留全部独立 RGBA 图片。

动作顺序：身体后藏好 → 探出 → 弯肘伸展 → 接触箱沿 → 指尖轻扣 → 短暂握住 → 松开 → 弯肘收进身体后。根部始终在 `(418,731)`，前景遮挡由原马桶轮廓决定。原主角及背景像素不移动。箱沿的上表面在掌根下，前指垂在厚前唇，远拇指收向掌后。

用内置 image_gen 生成无球形肩头的抓握、张手、半握三种正式质感来源，原图和完整提示词在 `generated_*.png`、`prompts.json`。最终每帧均取同一张 `source_open.png` 的像素，离线逆向 TPS 对肘、腕和远端指节连续变形；另外两张图仅作形状参考。没有两张姿态 RGBA 混合，没有全臂交叉淡入，没有用整手缩放模拟握紧。臂部已局部校正到奶白玩具色，保留体积明暗。

`bake_sequence.py` 可用配有 Pillow 和 NumPy 的 Python 重新烘焙本目录。`contact_sheet.png`、`hero_frame_027.png`、`phone_frame_027.png`、`hand_preview.gif` 分别用于关键帧、原尺寸、375 宽与连续播放检查。`checks.json` 记录透明度、绿幕残留和逐帧哈希。

中间版本曾发现填孔造成绿色残片，以及两张不同手指轮廓叠加造成重影，均已在当前 `single-surface-finger-warp-r2` 版本移除。自然程度仍以独立整体小样审核为准，不能据帧数或静态校验宣称已经获得用户视觉认可。
