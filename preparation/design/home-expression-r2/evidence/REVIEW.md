# R2 独立动作小样自查

日期：2026-09-15。此为首次 R2 的历史自查；用户随后反馈“这版还行”，并要求再活泼一点、云也要移动。当前页面已进入 [活泼度与云层细调](livelier-r1/REVIEW.md)，本目录原录屏及哈希仍仅对应首次 R2。尚未接入游戏。

## 本次修正与自查

最小方案是局部连续图片序列：保留正式主图，离线制作眼睑和手部姿态，浏览器按原图坐标合成。当前动作不需要引入骨骼系统、运行时变形框架或新依赖。

| 检查项 | 最终候选表现 |
|---|---|
| 眨眼 | 原眼球、瞳孔和高光不缩放、不移位；眼睑逐步遮挡，闭合快、睁开稍慢。 |
| 原画保护 | 修掉初稿鼓起的眼罩形眼皮、亮环，以及鸭子嘴沿少量被遮盖的像素；眉、嘴、主体轮廓保留。 |
| 手臂出入 | 从马桶身体后方探出，收回同一遮挡处；不使用球形肩头、整臂淡入或整臂旋转。 |
| 手指 | 使用单一手部表面连续变形，去掉初稿两姿势混合造成的重影指尖；手掌先到箱盖，手指再轻扣箱沿。 |
| 角色回应 | 接触后箱子才短促抬下眼睑；身体及其他五官不跟着漂移。 |
| 节奏 | 先看、探手、轻扣、箱子回应、松开收回，随后留白；不让角色持续同时运动。 |

正常速度、375×667 视口和局部放大均已检查，并进行独立对抗式复核。当前动作读作“轻扣箱沿”，不把它描述为明显拉扯。放大后远侧拇指边缘仍能辨认出绘制的遮挡关系，这是本候选需要用户判断的视觉边界。
