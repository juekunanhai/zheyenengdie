# R2 活泼度与云层细调

2026-09-15。用户反馈首次 R2“这版还行”，要求再活泼一点、云也要移动。本轮只更新独立小样，尚未替换生产首页。此为前版记录，当前页面已进入[拖鞋双手与用力表情](../slipper-grab-r1/REVIEW.md)，本目录旧录屏/哈希仅对应云层细调版。

## 原因与最小修正

原首页的大云已画在背景里；额外可动云处于边缘且移动缓慢，所以用户看到的主要云团仍像静止。仅加速边缘云不能解决这个问题。

| Before | After |
|---|---|
| 鸭子每轮只眨一次 | 0.70、1.12秒各眨一次，第二次约190毫秒，比第一次225毫秒更短；中间完整睁眼195毫秒。 |
| 手部过程2秒 | 同样49张姿态用1.8秒播放，接触位置、身体及手根不变。 |
| 箱子按旧手部时间回应 | 随手部同步到2.483秒，在接触后108毫秒回应，保持现有浅幅度。 |
| 8秒循环，收手后约3.7秒留白 | 6秒循环，收手后2.5秒留白，不用全体漂浮填充停顿。 |
| 显眼云烘焙在背景中，边缘云缓慢往返 | 上方主要云独立漂移，复用完整正式云素材，四层速度不同、方向相同；城市与中下远景保持原像素。 |
| 上一版缺少天空随进度定位 | 手动重播、拖动进度同步定位天空；自动角色循环则让云持续前进，整朵完全离屏后才重入。 |

这是复用局部帧与独立天空贴图的最小方案，没有添加骨骼系统、新依赖或新的玩法状态。

## 素材与画面检查

首次尝试提取原云时发现了多边形补片、云截断直边，已弃用。最终移动云是完整正式 `home_r9_cloud.png` 的原文件副本；内置 image_gen 只生成天空修补底图，城市仍取原图。仅使用 [最终云层合同](../../cloud/manifest.json)，不使用目录中保留的早期候选。

[云层来源、提示词与脚本](../../cloud/README.md)；[源像素保护检查](../../cloud/checks.json)。原背景426行以下的1,172,486个像素完全保留。上方屋顶、气球及边缘由单独天空遮罩保护，不随云移动。

手机尺寸检查：[0秒](cloud-0s-phone.png)、[6秒](cloud-6s-phone.png)、[12秒](cloud-12s-phone.png)。角色姿态及局部截图也保存在本目录。检查范围包括云边缘、Logo遮挡、手部接触及双眨时序；另经独立审查代理复核这些截图与实际正常录屏抽帧，未发现新增阻断问题。当前文件哈希见 [最终记录](FINAL_REVIEW.json)。
