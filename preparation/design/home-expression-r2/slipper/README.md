# 拖鞋双手扒住鸭子

用户要求：前景拖鞋从右边伸出双手扒住下方鸭子，表情显得用力。本轮仅接入独立首页小样。本文为上一版“长手伸收”的历史说明；当前已按用户修正为[短手持续扒头、闭眼微颤](hold-r2/README.md)。

## 最小方案

新增两条红色软胶手臂与白色玩具手套，一前一后扣住鸭头右后下缘、背部翅根上沿；手根从鞋右下缘后探出。鞋、鸭和后景拖鞋保持原位。两手接触后再收眼、抿嘴，短暂发力后恢复原笑脸并收手。

使用现有PNG局部帧播放器：双手49帧，表情7档。新增图层按750×1334首页坐标绘制，原鸭子和马桶局部动作继续使用原主图坐标。只有当前存在的两种坐标空间，没有新增骨骼库、运行时形变系统或生产配置。

## 当前时间

- 马桶探手：1.70–3.50秒，沿用前版。
- 拖鞋双手：3.90–5.90秒；约4.65秒两手均贴住鸭子，随后用力。
- 拖鞋表情：4.67–5.21秒；逐级收紧、保持、放松。
- 全段8.2秒，收手后留白2.3秒；云层持续移动，不随角色循环重置。
