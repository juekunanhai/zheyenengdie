# 短双手持续扒住鸭头 · 独立候选

本次按用户反馈，将原来伸到鸭背的双臂缩短：远手搭在鸭头右上沿，只露出部分指节；近手在鸭头右侧上半部抓住。两手从鞋右下缘后方连出，掌心接触后固定，不伸到鸭背、翅根或下颚，不收回。

## 最小实现与来源

复用上一版内置 `image_gen` 生成并提取的同一像素表面，仅调整已有离线 TPS 形变脚本的关节与手指控制点。没有生成整图，也未修改鞋、鸭、生产资产或代码。不增加骨骼系统或运行时依赖。

## 播放约定

- RGBA 280×340，39 帧，24fps；`rectStage=[405,475,140,170]`，对应 750×1334 设计画布。
- 0 秒从鞋后伸出；`contactSeconds=loopFrom=14/24`，约 0.583333 秒两掌固定。
- 循环区间为 `14/24` 至 `38/24`，长度恰好 1 秒。第 14 与 38 帧像素完全一致。
- 首次到达 `durationSeconds=38/24` 后，只循环握持区间。不要重播伸手、不要因首页其他角色循环而重置。
- 持续循环只改变肘、腕和指尖极微量的拉紧程度。根点和掌心不移动；没有位移、淡入、姿态交叉渐变或收回帧。
- 两掌参考图坐标固定为：远手 `(412,352)`，近手 `(435,395)`。掌心位于鸭头右侧；原鸭眉、眼、嘴区域不被覆盖。原鞋遮挡手根。

## 自查与边界

[完整连续帧](contact-sheet.png)、[局部握持循环](hold-loop.gif)、[375 像素手机首中末对比](phone375-loop-comparison.png)、[完整首帧组合](phone375-frame-014.png)、[检查数据](checks.json)。手机组合是在既有 375×667 静态审阅截图上以正式设计坐标合成新增手部，用于独立资产定位检查，不是 Cocos 构建或实际播放证据。

检查确认尺寸一致、循环首尾像素相同、循环掌心固定、最后帧仍握持；原鞋遮挡区域与受保护鸭脸区域的覆盖像素均为 0。扩大检查能看见两手前后错开、红软胶臂与鞋后边缘相连；手机尺寸可读作短手扒头。最终脸部用力表情与长时间播放由外层小样一起审查，本资产检查不代表用户已经认可自然度。
