# 短手持续扒头、可爱闭眼用力

本轮按用户修正：双手只扒鸭头，不伸到身体，不收回；眼睛闭起来可爱地使劲，嘴持续微抖，不在短表演后恢复原脸。

## 最小实现

- 双手复用已有生成材质，调整离线制作脚本中的臂长与握点。近手距离约缩短一半，双掌落在鸭头右上/右侧上缘，避开眼、眉、嘴。
- 首次约0.58秒伸手到位，之后始终保持握持；掌心和抓点固定，仅指尖、肘腕微微收紧。
- 接触后约0.18秒闭眼，之后始终是饱满的挤眼和小小鼓劲嘴。只有嘴持续3Hz微颤，每轴最大约0.285手机像素。
- 普通角色沿用原片段循环。拖鞋和云共用原有的连续计时，没有新增计时状态；首次进入后只循环握持/闭眼段，不受8.2秒普通角色回放影响。
- 没有骨骼系统、运行时形变库、新依赖或生产配置。
