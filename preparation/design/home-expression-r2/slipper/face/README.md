拖鞋局部用力表情候选，供首页独立动作小样使用，尚未写入 Cocos 工程。

原图为 `assets/batch0/art/home_r9_slipper.png`（340 × 257）。`manifest.json` 的 `rect` 使用原图左上角坐标 `[197, 106, 111, 94]`，即 left / top / width / height。7 张 `effort_00.png` 至 `effort_06.png` 均为 111 × 94 RGBA；第 0 张完全透明，后续为递增的用力强度，可倒放恢复。

当前版本为 `pinched-corners-effort-r2`。表情保持原本的黑色亮面眼睛和嘴，不切换另一张脸。眼睛收紧但保留约六成高度；嘴采用非线性局部变形，中间抿紧、两嘴角保留饱满，带轻微不对称，避免三处统一压成细线而像困倦。没有倒 V 眉、叉眼、露牙、愤怒或痛苦标记。拖鞋的条纹、材质高光、形状和外轮廓不动。两只手接触鸭子后才收紧，推荐约 160 ms 进入、350 ms 保持、220 ms 放松；动作因果由小样播放器负责。

生成流程使用内置 `image_gen`，实际提示词见 `prompt.txt`，输出参考保存在 `generated-effort-reference.png`。生成参考的抿嘴方向被用于局部变形设计，整张生成鞋、生成背景及其他漂移像素均未替换正式素材。最终可用的表情来自同一份原始表面几何变形，使用 `bake_effort.py` 离线生成，未将两个不同表情做透明度交叉叠化。红色塑料补底仅限眼嘴被压缩后露出的局部区域，按原图边界颜色连续重建。

查看 `contact-sheet.png` 检查源尺寸细节；查看 `phone-contact-sheet.png` 和 `phone-preview.gif` 检查前景拖鞋约 97 px 宽时的可读性。用力表情需要结合已经扒住鸭子的手势，避免脱离上下文把收眼误读为普通眨眼。

`checks.json` 记录资源尺寸、首帧透明、保护区像素不变和原图未改。这些技术检查不能替代用户对动作自然度的审阅。源素材和生成参考散列记录在 `manifest.json` / `PROVENANCE.json`，所有文件限于当前独立小样目录。
