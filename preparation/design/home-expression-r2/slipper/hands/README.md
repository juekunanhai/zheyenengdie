# 拖鞋双手扒鸭：独立动作候选

使用内置 `image_gen` 对 `../reference-pair.png` 做局部增补生成，[完整提示词](prompt.txt)。母图是 [generated-pair.png](generated-pair.png)。生成时的鞋与鸭并未作为成品替换；离线脚本仅提取新增红软胶臂和白色手套，合成底图始终为原 `reference-pair.png`。

最小实现是同一像素表面的离线局部形变，输出普通 RGBA 帧；不增加骨骼、运行库或生产工程配置。两手分别有固定掌宽和独立肘/腕位置，手指轻卷，无两种姿态的透明混合。身体不移动。原鞋遮挡手根，接触影仅落在原鸭的黄色材质上。生成图中的棋盘背景已从局部提取中去除，白手套内部纯白高光保留为不透明。

## 接入约定

- `manifest.json` 的 `rectStage=[405,475,140,170]` 是 750×1334 画布中的 x、y、宽、高。
- 49 帧，24fps，2 秒，PNG 每帧 280×340；直接绘制，不再旋转、位移、透明淡入。
- 0.34 秒探出，0.73 秒两手接触，0.92–1.12 秒轻扣用力，1.31 秒放松，1.9 秒收回藏于鞋后。
- 第一和最后帧均透明；角色力气表情由独立脸部资产负责，建议接触之后再出现。
- 远手扒鸭头右后下缘，近手扒鸭背/翅根上沿，避开嘴、眼和喉咙。
