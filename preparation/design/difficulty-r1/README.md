# 基础难度 R1：冻结美术与真实承托几何

2026-09-13，用户确认“可见承托面修正 → 落地缓冲 → 长木板局部稳固”的最小实验。本目录提供纸箱、冰箱、木板三件正式质量试玩候选，不代表其难度或木板连接已经通过引擎验收。

- 纸箱：100.912779 × 100，顶面 77.484787，底面 94.827586 世界单位。
- 冰箱：110 × 133.554084，顶面 80.982340，底面 96.037528 世界单位。
- 木板：260 × 28.744805，顶面 249.193682，底面 250.058188 世界单位。

所有尺寸从真正 alpha 外边界与肉眼所见平面提取，再按一个统一比例映射世界单位。没有把像素尺寸直接充当物理尺寸，没有横向拉伸，没有将凹槽填平，也没有为上方物体增加不可见平台。纸箱顶部比名义 80–90 略短，采用真实的 77.48；冰箱按生成实形选宽 110，高度随比例得到 133.55。

图片由内置 `image_gen.imagegen` 纯文字生成，一件一调用，没有提交本地图或上传项目文件；原图、全部提示词、两张因比例不合格而淘汰的原图均保留。没有调用第三方图片站或用历史 UI 抠图。当前正式源目录保持原样。

`prepare_assets.py` 只保留原生成主体及其 2 像素抗锯齿边缘，去除外部孤立 alpha 残片，裁切并留 6 像素透明边，使用同一 alpha 制作 NEXT。没有修改主体 RGB，也没有增加 alpha。轮廓水平段只简化了 1–2 个源像素的微小波动。`PROCESSING_AUDIT.json` 记录每件处理数量与哈希。

`GEOMETRY_CHECK.json`：三件多边形无自交；NEXT 与 Sprite alpha 完全一致；轮廓距 alpha 边界最大误差分别约 0.220、0.332、0.290 世界单位。几何与图像冻结后不再调整；质量、缓冲、木板连接和实际可放范围由主任务引擎实验决定。

`index.html` 用于看图与叠线自查；`GEOMETRY.json` 为导入数据。图片路径位于 `assets/`，不应将 `generated/` 的未处理原图直接用于游戏。
