# 冰箱 R2：真实八边主体

原 R1 圆角冰箱忠实描边需要 34 顶点，硬压至 8 点的最大误差达到 4.846 世界单位，因此拒绝直接简化。此候选重新生成八边真实外壳：平顶、平底、竖边、短倒角；趣味眼睛、圆润搪瓷门和金色星磁贴放在外轮廓内部。

此处保留两张纯文字内置工具生成原图，未提交本地图，也未覆盖任何冻结的 R1 图或几何。首张八边形完成但偏高，110 宽对应 147.33 高；第二张采用更矮宽的比例，110 宽对应 122.873563 高。此候选不强行拉伸成名义 110 × 133。

第二张八点凸形面积 13165.444595；水平顶面 84.252874、底面 84.367816 世界单位。最大 alpha 边界误差 0.867369 世界单位；0.0603% 面积是边缘亚像素近似，没有增加可见平顶以外的隐藏承托。Sprite 与 NEXT alpha 逐像素一致，主体 RGB 保持生成图原样。

`GEOMETRY.json` 为冻结候选，`fridge-geometry.png` 是已人工查看的叠线图，`PHYSICS_CHECK.json` 验证严格凸与八顶点，实际 fixture 数量仍需引擎导入确认。`SOURCE.json` 记录原图、完整提示词、淘汰理由与冻结文件哈希。`PROCESSING_AUDIT.json` 记录只清理外部 alpha 噪点、保原抗锯齿边缘和裁切的过程。

## 125 宽的必要承托调整

引擎 QA 发现哑铃双脚内缘约相隔 71.46，110 宽版本的顶面 84.25 每侧只有约 6.4 的承托余量。新 `GEOMETRY_125.json` 将同一张图、同一组八顶点的世界映射统一乘以 125 / 110，得到 125 × 139.629049，顶面 95.741902、底面 95.872518，面积 17000.832380。理论几何余量每侧约 12.14，实际放置容错仍需物理验证。

这次只基于双脚承托需求选择世界尺寸，不是把像素尺寸直接充当游戏尺寸；没有重绘、重采样或横向拉伸图片。最大边界误差 0.985647 世界单位，仍小于 1，因此不再盲目加宽。125 版仍严格凸且只有八点；质量目标保持纸箱的 1.6 倍，需要根据新面积调整密度。原 110 版 GEOMETRY、SOURCE、PNG 和 NEXT 的冻结哈希全部未改。来源增补见 `SOURCE_125.json`，诊断叠图见 `fridge-geometry-125.png`。

## 150 宽当前试放候选（待玩法验证）

连续左右各偏 10 的动作可能产生 20 单位的相对偏移。`GEOMETRY_150.json` 将同图同八点统一等比映射为 150 × 167.554859，顶面 114.890283、底面 115.047022，给哑铃 71.46 的双脚内距约 ±21.715 的名义几何余量。面积 24481.198627，密度约 0.293776465342 可保持原生质量 7.0234375。本轮已选择此候选供试放；最终平衡仍需玩法实验。

此时最大轮廓误差准确为 1.182775439 世界单位，已明确超过 1 单位目标，`passes_one_world_unit_limit` 为 false。最大误差在左下倒角；上下水平承托线全段及四个端点与 alpha128 边界均精确一致，误差 0 源像素。不能把更宽说成仍满足 1 单位目标。按当前已验布局换算，375 幅最大差约 1.035 CSS 像素、600 幅约 1.150 像素，并不是 0.6 像素。125 版本、PNG、NEXT 及所有冻结来源均未改。
