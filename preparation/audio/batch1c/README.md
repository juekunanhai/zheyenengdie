# Batch 1C 原声音乐与材质声音

本目录提供 3 个同主题 BGM 和 9 个材质音效，制作脚本为 `preparation/tools/build_audio_batch1c.py`，本身不导入运行目录、不修改场景或配置。来源、状态、母版与导出哈希均见 MANIFEST.json。

- 音乐统一 35.64 秒、1,571,724 帧、44.1 kHz、双声道，MP3 128 kbps。三版共用同一尤克里里录音原速原调，不是三首无关曲。城市 16 次轻木敲，云层 8 次，太空无木敲；本地短反射递增。
- 原始 17 秒素材不是可直接首尾连接的完整循环。选取 0.80 秒开始的约 8.91 秒重复乐句，前 60 ms 混入下一乐句同位置的连续尾音；重复 4 次并作稳态滤波。三版音乐连续性以共同节奏和共同相位建立，没有自动合成旋律或重新演奏。
- soft、ice、heavy 各 3 项，44.1 kHz 单声道 MP3 96 kbps。soft 0.29 秒、ice 0.35 秒、heavy 0.48 秒。冰块采用玻璃轻敲拟音代理，重物采用软物与厚木混音。
- 运行集成建议复用两个受生命周期控制的 AudioSource；高度阶段改变时新曲设为旧曲对应 currentTime（模共同长度），进行 1 秒线性淡化。首次播放仍从用户操作后触发；关闭/后台不得自动重新开声。
- MP3 文件解码具有连续样本，不证明目标平台 MP3 播放器无循环间隙；需要真实引擎和设备单独验证。

试听入口：`preparation/review/audio-1c.html`。用户授权了采集和当前采用，主观听感未逐项签收。
