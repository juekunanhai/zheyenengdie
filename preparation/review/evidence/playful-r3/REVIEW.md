# 配乐 B 与人声接入 · R3

用户选择配乐 B，并认可 Wow、Hey、短笑，授权寻找切入点并开始开发。本页记录本批实现和实际验收，不能用旧 R7 通过结果代替新音频回归。

## 最小实现

- 配乐使用 Happy Boy End Theme 的第一速度段完整配器乐句，原速原调，约 14.328 秒。去掉原曲中段停顿，以 60 ms 周期接缝处理首尾；三个高度引用保持原 UUID，统一使用 B 的相同配器，不伪称三个新编曲。音乐自然循环和相位切换单独检查。
- Hey：每局首个有效放置触碰一次，进入 planning、镜头恢复且没有掉落危险时响应。普通首场景进入本身不触发，避免冷启动没有用户交互而丢失招呼。
- Wow：真实稳定成绩跨每个 5 米档时尝试一次；一次跨多个档也只尝试一次。同一成绩不重复触发，冷却或静音拒绝后不补播。
- 短笑：本次新确认稳固的鲸鱼、汉堡、马桶或拖鞋中，首次符合播放条件时触发，每局最多成功播放一次。同次有里程碑时 Wow 优先；短笑拒播后只能响应后续另一个新的放置事件。
- 三个人声共用 12 秒冷却、最多一段，沿用八个音效声源和四个碰撞槽。音乐在人声期间从 0.22 暂降到 0.09，再平滑恢复；没有新建音频总线或事件系统。
- 事故、失败立即停止人声；碰撞和掉星声音仍能播放。暂停、后台、结束取消人声，恢复不补播。
- 设置页下方增加四行静态音乐署名：曲名、作者、CC BY 4.0 URI 和剪辑说明。原设置按钮与交互保持。

本批为现有声音接入，不实现危险高光识别、导演、道具或新的评分规则。原物理、难度、十二物体几何及事故判定保持。

## 首轮发现的问题

[VOICES_R1.json](VOICES_R1.json) 证明三个人声真实 STARTED / ENDED 和两次自然等待 12 秒冷却通过。

[ASYNC_CANCEL_FAILURE_R1.json](ASYNC_CANCEL_FAILURE_R1.json) 记录真实失败：首次播放后立刻停止，仍收到迟到的 Wow STARTED。Cocos 在 AudioPlayer.load 未完成时将 PLAY / STOP 依序排队，单独 stop 不能消除开始操作。

修正仅针对人声：停止时同时解除 AudioSource.clip，使在途加载失效；暂停和销毁复用同一取消方法。事故仍只取消人声，未暂停整个音效模块。首轮构建、源码与失败证据已冻结，修正版重新构建并重跑。

## 最终验收

[ENGINE_R2.json](ENGINE_R2.json) 保存修正版实际 Web 引擎七项全部通过的原始记录：

| 检查 | 实证与边界 |
|---|---|
| 三人声与冷却 | 三个实际 AudioSource STARTED / ENDED，真实等待两次 12 秒，共享冷却拒绝并发且不补播 |
| 开关与中断 | 静音拒绝、暂停冻结声音时钟、恢复不补播；后台由 Cocos hide/show 事件模拟，未当作手机系统后台 |
| 事故/失败 | 立即取消后不再出现迟到 STARTED；显式事故/失败条件打断人声，同时碰撞仍可播放 |
| 音乐降低/恢复 | 实际控制器 lateUpdate 与人声事件驱动，采样 gain 0.22 → 0.10354 → 0.21546；目标为 0.09 和 0.22 |
| 控制器事件 | 受控稳定成绩跨档、一次跨多档、冷却消耗及短笑单次；虚拟成绩单独标记 |
| 默认序列真实放置 | 居中指定释放、不改落物位置与物理；14 次释放最终 14 件确认，11.4819m、3 星、0 事故。Hey、短笑、Wow 均真实 STARTED，间隔约 12.98 / 12.88 秒；单局指定操作不代表真人胜率 |
| 循环与高度切换 | 音乐时钟自然回绕 14.3238 → 0.0001 秒；60/170m 为受控输入，两次约 1 秒淡化，实测双源相位差最大约 0.0001 秒。不是自然堆至高空的证明 |

循环 WAV 母带为 14.328367 秒；Cocos AudioClip 的 MP3 容器时长报告为 14.367347 秒，实际播放回绕以运行 JSON 为准，不把不同口径写成完全相同。

R2 全量来源/范围/构建门禁 exit 0，312 个当前输入、298 个旧文件受保护。人工检查随后发现设置署名与返回按钮重叠，最终只把 MusicCredits 的 y 从 −390 改为 −540；三份音频代码及声音文件保持 R2 字节。R3 的最终构建与署名复核见下方及 [构建记录](BUILD_ACCEPTANCE.md)。七项音频证据仍明确属于 R2，不冒写成 R3 重跑。

最终 R3 实际 Creator 构建 exit 36、项目 TypeScript `--noEmit --skipLibCheck` exit 0、全量完整性检查 exit 0，见 [BUILD_R3.json](BUILD_R3.json)、[VERIFY_R3_EXECUTION.json](VERIFY_R3_EXECUTION.json)。未加 skipLibCheck 的额外检查因 Cocos 引擎声明报错，完整边界记于 [BUILD_R3_EXECUTION.json](BUILD_R3_EXECUTION.json)，不声称所有引擎声明检查通过。

[UI_REVIEW_R3.json](UI_REVIEW_R3.json) 记录最终 375×667 实际浏览器核对：首页设置可打开、四行署名位于返回按钮下方黄色地面留白，无重叠或底部裁切，点击返回可回首页。截图在工具中实际查看，未另存本地图片。R3 唯一源码变化为署名坐标，音频回归引用 R2 原始记录。

当前未进行微信重建、真机音量/中断复验或发布。已批准的候选听感不等于循环剪辑、游戏内混音和手机扬声器的主观验收。
