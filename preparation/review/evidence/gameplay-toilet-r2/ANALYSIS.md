# 马桶 R2 物理对照：结果与边界

此文件记录几何诊断。当前最终轮廓使用 `candidate-b/GEOMETRY.json`，不是先前代理多边形或首张偏左水箱图。普通抓手结果另见 `LIVE_R1.json` / `LIVE_R2.json`。

## 先固定评价，再运行

用户本轮把初期体验重点明确为容易堆叠、合理位置有容错。因此最终试验不要求横移策略优于居中；优先检查原同点诊断与屏幕中线附近的容错。所有支撑都是动态刚体，未扶正、锁塔、改变隐藏重心或新增粘接。

最终 B 可见宽 150.900515、高 115。高台宽 90.93482（x=-68.940823..21.993997），脚平底宽 128.610635。没有横向拉伸图片，也没有把真凹口填成凸包。密度取 0.401990728786，维持 R1 原总质量；重心与惯量自然随真实轮廓变化。

## 完整结果

`FINAL_COMPARISON.json` 共 384 场、82,415 个真实 Cocos 物理步，无浏览器运行错误。原生刚体总质量相对差为 9.55e-8；代表动作、固定组合与搜索选出动作各重复 3 次，稳定落件数一致。

| 指标（每种载荷） | R1 | B |
|---|---:|---:|
| 原世界坐标 x=-40..5、步长5，纸箱 | 0/10 | 10/10 |
| 同上，冰箱 | 0/10 | 8/10 |
| 中线 x=-15..15、步长5，纸箱 | 0/7 | 7/7 |
| 同上，冰箱 | 0/7 | 7/7 |
| 各自可见高台中心±15、步长5，纸箱 | 0/7 | 7/7 |
| 同上，冰箱 | 0/7 | 5/7 |

B 两种载荷包含 x=0 的连续成功采样点覆盖预先规定的 [-15,15] 窗口。±15 是本次测试窗口边缘，不是测得的最大容错；网格间所有实数位置没有穷举。成功要求连续稳定≥0.65秒、马桶仍近似直立（12°内）、载荷仍高于脚底50世界单位，掉到地上停住不算成功。

最终轮廓冻结后已重新跑全部 384 场。`BEFORE_FINAL_CONTOUR.json` 是此前中间轮廓的报告，不作为当前结果；两轮不能混用。最终冰箱 x=-35、-30 在原细扫中仍失败，但预定的世界中心±15窗口全部通过。

## 没有改善或需要重新摆法的部分

- 固定旧 H01（哑铃 x0/180°，下一件木板 x0/270°）由 2 件稳定退化为 1 件；不能称原动作回归通过。
- 只用原先既有 C 动作集（x0/±30、四朝向）重搜同两件，B 的哑铃 x-30/180°、木板 x+30/270°可稳定2件，三次重复一致。这是新几何的新摆法机会，与旧动作结果分开呈现。
- 纸箱→木板→马桶固定居中组合 R1/B 都3件稳定。
- 低盖台篮球固定 x35 R1/B 都稳定。
- 横放马桶90°落到居中纸箱，R1/B 均失败。没有因为新形状只改善某些姿态，就隐藏其他失败。

## 代理实验的作用

`PROBE.json`、`CENTER_PROXY.json`、`CENTER_MARGIN_PROXY.json` 是先于真实 B 轮廓的结构探针，均不作为正式图验收。它们证明扩大脚座与水箱高台需共同作用：只有窄脚或只扩大脚而保留窄高台，仍不能给冰箱合理承托。把高台跨过中线后居中成功率显著改善。代理轮廓的 +10 冰箱仍失败，但真实 B 更宽的脚座/台面通过当前全部中心采样；不要混用两套数值。

## 仍须普通抓手验证

所有上表使用旧实验固定80世界单位落差、8秒稳定等待，排除普通镜头/抓手释放高度、倒计时和事故规则。不能据此直接宣称真实六件流程全部通关或人类游玩已足够轻松。

R1 普通真实控制器基线已记录：前三件居中，第四冰箱 x0 与 x-30 两种方案均在第四件失败，均3/6。B 最终真实新构建：全居中6/6，第四件起沿用-30方案仍3/6。另四套仅改变第四冰箱（其他件都居中）：-15为3/6，-10为6/6，+10为4/6（冰箱稳、随后哑铃掉落），+15为3/6。额外四套未补做R1同点配对，因此只作为R2正常容错诊断。

普通抓手第四冰箱实际离塔顶约108.57世界单位，下方还有纸箱/木板动态支撑并有约0.46°自然倾斜，条件比80单位探针不同。当前证据不能单独断定落差或倾斜哪个是失败主因。可以确认中心六件已打通，但不能声称正常流程整个±15窗口均宽容。

LIVE_R2已把当前编译spec逐字段与FINAL预期值比较，同时记录并核对真实Collider点集、density、friction、restitution与动态getMass，全部匹配；没有仅凭源代码或代理物理宣称集成通过。

`FINAL_INITIAL_WAIT_FAILURE.json` 是试验前 QA 等待变量未加 window. 导致的 0 场失败记录，已修正；没有物理数据或游戏失败结论。
