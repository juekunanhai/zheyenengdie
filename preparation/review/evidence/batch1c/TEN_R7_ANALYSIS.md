“有效确认”和“支撑”会重叠，不能相加；“未确认”只统计仍有效的物体，失效体另列。第一局历史 placed 为 8，但其中汉堡已失效，所以首14有效确认仅 7。第3局首14均有支撑，但后6件尚未完成稳定确认。

本局已确认高度峰值范围 **7.21–15.11 m**，平均 **11.60 m**，中位数 **11.54 m**。这是结算使用的有效塔体历史峰值，不是结束瞬间残塔高度。

计数方法：取前 n 次实际释放的物体 ID 去重，再从 `drops[].before.releases === n` 读取准备第 n+1 次释放之前的状态。未到达下一次释放的局记“未到达”，不补通过。`placed && !lost` 表示此前通过真实稳定确认且当前有效；单帧 `supported` 或低速度不能证明连续 0.65 秒稳定。

时序边界：本十局在 `AFTER_UPDATE` 回调内快速释放，进入当帧后续物理步；单局全居中压力脚本在 `AFTER_PHYSICS` 后继续释放，最早进入下一物理步。它们没有固定同一帧 delta 和物理累计器，不承诺同配方逐帧重现。没有将统计差异全部归因为事件时序。

真实触摸、真人连续十局的乐趣、手机扬声器与微信真机行为仍不由本记录证明。
