# Batch 1C 本地开发与验证记录

2026-09-14。当前运行版本为 Web R7。十二物体和原声音乐已可试玩；本批尚未完成微信包体、首页启动和真机验收，不进入 Batch 2。

## 本批交付

- 补齐木箱、沙发、汉堡、冰块、拖鞋、鲸鱼，十二物体均有正式 Sprite、同源 Alpha 的 NEXT 与按真实轮廓分解的 Box2D 碰撞片。
- 五件必要重绘包含汉堡的局部平顶、平底修正。保留可见凹口与材质细节，不使用隐形承托面。汉堡质量仍为 3.2，没有新增普通物体强胶。
- 新增三版同主题原声背景音乐与九个材质声音，素材来源与许可留在 `preparation/audio/batch1c/MANIFEST.json`。背景音乐使用两个音源，同相位淡化，随实际视区高度切换；事故降低音量，暂停、设置关闭和换场均受现有生命周期控制。
- 基础出物改为十四件覆盖十二种：纸箱、木板、冰箱、木箱、沙发、鲸鱼、木板、汉堡、冰块、哑铃、木板、马桶、拖鞋、篮球。已展示的 NEXT 不在中途更换。

最小方案沿用现有物体规格、物理、事故和表现结构。相比旧十九件顺序，减少四块重复木板和一件重复冰箱，降低约 20.97 的累计质量；没有提高已认可胶层力矩、锁死塔底或新增自动落点系统。两个音乐音源是淡出、淡入同时进行的必要复杂度；完整导演仍属 Batch 2。
