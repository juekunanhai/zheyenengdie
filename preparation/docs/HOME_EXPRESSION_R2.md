# 首页 R2 正式源码接入

2026-09-16。接入已审阅的 `home-expression-r2` / `slipper-hold-r2` 小样。当前完成 Cocos 源码、资源引用和静态检查；没有启动项目、Creator 或浏览器，没有构建 Web/微信或执行真机验收。

## 最小方案与复杂度判断

直接在现有 `HomePresentation` 内播放局部 SpriteFrame 序列，保留首页现有按钮、音乐、场景路径及飞机/飞艇轻微运动。一个 `elapsed` 递增计时驱动全部动作；沿用 `trickAt` 字段作为点击主体时普通片段的相位偏移，它不累加、不影响拖鞋或云。无需骨骼、运行时形变、通用播放器、异步加载队列或新的业务状态。

## 资源与来源

- `assets/batch0/home-expression-r2/`：只复制小样实际引用的 126 帧和 2 张天空/城市层 PNG，像素未改；不导入生成母图、录屏、旧版动作或制作辅助图。
- 原云图继续引用 `assets/batch0/art/home_r9_cloud.png`，与小样 `moving-cloud.png` 字节一致，没有额外复制云。
- `preparation/tools/import_home_expression_r2.py`：按源清单生成稳定 UUID、无裁边 SpriteFrame meta、序列帧索引和 Home 场景引用。重复导入结果一致。
- `preparation/design/home-expression-r2/COCOS_IMPORT.json`：每张图片原路径、目标路径、SHA-256、字节与 RGBA 估算。

| 范围 | PNG 数量 | 文件字节 | RGBA 解码估算 |
| --- | ---: | ---: | ---: |
| 局部动画帧 | 126 | 2,004,487 | 41,127,024 |
| 加上去云底图和城市前景 | 128 | 5,376,371 | 53,713,840 |

RGBA 数值按 `width × height × 4` 求和，仅用于资源规模评估；不含引擎、其他首页图、纹理副本或 GPU 压缩，不是运行时峰值。尚未验证微信产物体积、首屏加载和真机内存。

1. `node preparation/tools/check_home_expression_r2.cjs`：实际生产 TS 转译后在最小 `cc` mock 中执行，3374 项断言通过。463 个时点与原小样逐帧一致，覆盖每个切帧边界、首次握持以及 8.2/16.4/24.6 秒循环边界。
2. 同一脚本覆盖四种画布尺寸的拖鞋/手/脸配准，云完全离屏后循环、城市层级、后台冻结与前台续播、主体连续点击、按钮 0.96 按压、重新启用和销毁事件清理。
3. 同一脚本逐张核对原图 SHA-256、帧数组索引、SpriteFrame UUID、源尺寸、无裁边 meta，以及正式云图复用。
4. `node /Applications/CocosCreator/3.8.8/CocosCreator.app/Contents/Resources/resources/3d/engine/node_modules/typescript/lib/tsc.js --noEmit --pretty false --skipLibCheck` 通过。`skipLibCheck` 仅跳过 Creator 自带声明中的已有类型问题，没有改项目配置。
5. 重复运行导入脚本，269 个所列文件的哈希不变；`git diff --check` 通过。
