## 篮球双面胶与最小方案

用户确认“平台对齐＋篮球上下双面粘连”。摩擦 0.85，接触角阻尼 6、腾空 0.1，弹性从 0.28 降到 0.03；圆形半径 34、密度 0.4 及出物顺序不变。介绍文案“别担心，有人给它贴了双面胶。”仍保存在 ObjectSpec.description，介绍 UI 按原定批次接入。

最小方案采用现有 TowerWorld 内的接触事件、材质数据和 RelativeJoint2D。上下各最多一个连接，法线竖直分量绝对值至少 0.7 才接受；侧擦不粘。连接在物理步后建立，以当时局部位置与相对角度为基准，不自动扶正。最大力 1500、力矩 150、纠偏系数 0.4；相对位置偏离超过球宽 12%（8.16 世界单位）或端点失效时解除。保留真实端点刚体、质量及碰撞，重开先移除原生连接再清理物体。

新增连接是当前需求必需：摩擦与阻尼无法维持两物体的相对位置。试验还表明只连接不缓冲，会把冲击传到冰箱，因此在首次有效胶面接触处限制过大的靠近速度，普通目标为 2 Box2D 速度单位/s（64 世界单位/s）；不改自由落体、切向速度或全塔重力。旋转接触的平动修正另有限幅，避免倒转运动。未新增运行脚本、npm 包或完整强力胶道具系统。

验收沿用正常释放高度连续投放五件，覆盖第五件居中和左右各偏 15 世界单位（纸箱宽度 15%）；三例均落稳，冰箱最大偏转不到 0.4°。另验侧擦、强力拉开、移除支撑后的球/整塔下坠、旋转冲击和重开。正常触摸控制器也完成第五件落稳。证据为 ADHESION.json / INTEGRATION.json；不是任意偏心或长局稳定承诺。

R3 的“滚动距离减少约 76%”和斜面滚落检查保留在 ../review/evidence/batch1a-before-adhesion，不能作为当前粘连验收。校准中曾发现两个速度 API 的单位不同，错误换算会反向加速；已按安装版源码修正，真实接触速度与旋转反例已加入当前检查。

## 实现与最小结构

一个 Creator 工程、一个互斥放置状态：入场→规划→下落→观察→下一件或结束。物体数据、塔物理、画面、输入/本地存储/生命周期、音频入口与场景动作分开维护；未引入 ECS、事件总线、远程配置、通用平台空壳或新 npm 依赖。

物理节点独立于缩放的 UI 根节点，始终使用原世界单位。Sprite 等比显示，通过表现层映射保持 R6 构图；有效塔底进入屏外后仍是动态刚体。画幅变化只重排界面和待放物，不缩放已落地刚体。完整深层辅助算法在 1B。

当前校准序列为纸箱→木板→冰箱→篮球；木板是实际投放物，并非物品间自动生成的垫层。用户轻触或拖动松手释放，旋转按钮独立消费事件；首局前两件免自动释放，之后 4 秒，旋转不重置倒计时。

## 校准数据与修复

- 1u=100 世界单位=1 显示米。纸箱 100×100，木板 195×28，篮球半径 34，冰箱 82×145；平台宽 160。物理父级比例为 1。
- 实际 PhysicsSystem2D：重力 y=-1000，固定步长 1/60，maxSubSteps=4，唯一自动步进。生命周期通过公开 resetAccumulator 丢弃积压，不读写私有 accumulator。
- 375×667 下首件纸箱最低点到平台顶面约 **3.854u**。旧 3.67u 是 R6 画面估计，并非 Collider 标定值。木板旋转竖直后底端约 290.429 世界单位，首箱顶面约 100.5，仍有约 1.90u 的放置间隔。
- 修复 180° 时 Euler 回读分支导致的旋转回跳：逻辑记录四向旋转次数，表现复制四元数，边界按平面角计算；测试另查实际物理方向。
- 修复结束卸载时子节点已销毁仍解除监听/再次销毁的问题，结束→重开已通过。
- 运行 resize 的旧反例来自桌面固定容器仅改 CSS。验收宿主现通过公开 screen.windowSize 通知引擎；750×1334→750×1624 时安全区锚点仍为 0.5、塔底位置不变、待放顶边同步更新。该宿主代码只在 preparation，不进入游戏 assets。
- 屏外六箱测试使用刻意放大的外部冲量 150，确认底部和顶部均产生运动。小冲量 25 被满载支撑摩擦大幅吸收，不能把它当作冻结反例；本测试证明传递存在，不代表深层辅助或自然难度已经调好。
