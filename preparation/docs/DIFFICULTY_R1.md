# 前期宽容度与稳固木板 · difficulty-r1

2026-09-13。用户确认上一轮评审方案。本批工程、固定动作对照、局部反例及文档已完成；保留一条极近边缘放置失败，不宣称全组合通过。当前交付试玩复核，其他功能继续暂停。

## 本轮已确认方向

- 优先修纸箱、冰箱可见底脚与顶面，让合理放法有一段可用落点，且能承接后来物体。碰撞跟随真实素材轮廓，不增加隐形托板。
- 冰箱保留偏重特点，但降低相对轻底座过大的重量差；重量单独对照，不能把效果全归因于形状。
- 对新落物的首次真实承托接触提供有限冲击缓冲。空中、侧擦不吸附，不移动坐标扶正，不冻结刚体。
- 比较更长木板（225 / 260）并保持总质量，避免加长同时增加下落冲击。木板上表面防滑并缓冲后来撞击。
- 横放木板可与实际接触的最多两个直接下层动态物体建立有限强度连接。保留接触时的相对位置和倾角，只抵抗局部相对速度，不把物体强拉回旧坐标；严重拉开、扭转时解除。整段失去支撑仍会自由下坠。
- 普通物体普遍粘连不采用；通过承托几何、冲击缓冲、接触时角阻尼和木板局部稳固处理。篮球继续保留双面胶特色。
- 保留马桶 R2 和哑铃真实凹槽；本批先观察其他物体修正带来的组合收益。
- 前期荒诞物体可以早出现，合理落点应宽容。先用固定开局顺序验证，不提前制作完整导演。

## 最小方案与复杂度判断

沿用当前 ObjectSpec、TowerWorld 和互斥放置状态机。普通缓冲复用现有真实接触限速；只补可选物体参数。木板最多两个直接支撑的局部连接，是“木板加固承托层”明确需求需要的复杂度，单纯改摩擦或刚体硬度无法提供这个行为。

不引入通用支撑网络、全塔冻结、全局扶正、角色管理框架或新物理引擎。整塔和历史几何失误继续存在；深层距离辅助仍按后续 1B 规则单独实施。

## 对照和验收

旧构建与对应源文件、三件 Sprite / NEXT 已保存在 `review/evidence/difficulty-r1/before/`，不能用新版图和代码冒称原始版本。旧构建入口为 `review/difficulty-before-player.html`。

按同一真实引擎、同一抓手定位算法与同一操作比较：旧版 → 承托几何 → 质量调整 → 首次接触缓冲 → 木板局部稳固。225 / 260 木板保持总质量作长度对照，摩擦不同时大幅调整。实验参数尚非最终采用值。由于物体形状、承托姿态和镜头随状态变化，各次真实落差分别记录，不将其误称为恒定落差，也不手动搬动物体凑相同间隙。

1. 当前 1.5 秒交接下，居中、左右轻偏、连续同侧偏放等固定动作跑前 8–10 件。分别记录释放、下一件入场、真实稳定确认与停止操作后的存活，不能把超时出物当成功。
2. 当前件放下后继续承接两件，测可用落点范围；单件暂时没倒不算组合通过。
3. 木板单支点、双支点桥接、偏载各做连接开关对照，测下层晃动和后续承托是否确有改善。
4. 负例：无实际接触不建连接；竖板不成为稳固楼板；极端悬挑、严重偏载仍会翻落；失去支撑的连接段仍下坠。解除后不在同一持续接触中反复重新粘住。
5. 三件 Sprite / NEXT 同 Alpha，碰撞与可见平面一致；四向挂高、镜头净空、左右边界和多画幅用实际引擎检查。
6. 回归篮球粘连、1.5 秒观察、暂停、后续计分与旧物掉落监测。实际构建和证据对应当前源，不继承旧实验的通过数字。

## 已确认的接触问题与修正

初版细轮廓木板没有被引擎截断，但分解成 3 个凸片，最薄顶片不足 1 世界单位。普通抓手落差下，马桶穿入该薄片后同时受到反向法线和内部斜边约束，产生缓慢爬移。保留相同可见承托面并简化为 8 点单凸片后，三件能够正常静止；不是靠放大摩擦消除。纸箱同类薄片一并处理。详见 [原生碰撞片与接触证据](../review/evidence/difficulty-r1/NATIVE_FIXTURES_ANALYSIS.md)。功能性凹槽仍保留，不将马桶、哑铃强行包成实心矩形。

冰箱重新制作真实八边轮廓。125 宽候选的顶面只有 95.74，哑铃双脚内距 71.46，因此相对偏移容错仅约 ±12；交替 ±10 的操作会产生 20 的相对错位，导致一脚踩到倒角。最终试放候选把整图和碰撞统一等比映射到 150 × 167.55 世界单位，顶面 114.89、底面 115.05，同时保持质量。顶/底水平面及端点均贴合 Alpha128 边界；左下倒角的简化误差最大 1.183 世界单位（约 1.04–1.15 CSS 像素），明确不满足此前候选的 <1 世界单位自查指标，没有把它偷偷改成“通过”。此处作为公开的非承托拐角近似保留，当前由实际承托与视觉复核共同验收。纸箱 / 木板 / 冰箱在当前原生 Box2D 中均为单个 8 点碰撞片，面积完整，见 NATIVE_CURRENT_FIXTURES.json。

粘连使用引擎现有 RelativeJoint2D，并以真实接触姿态作为目标。已修正累计旋转角被四元数折回造成的整圈误纠正；181° 篮球支撑和 720° 木板支撑已做引擎反例。另发现初始接触穿入被存成胶层位置目标，球上下胶在七件静止时仍约以 1500 N 向下拉，和碰撞解穿相冲突。校正初始接触目标后该内耗消除；正向位置反馈在多件受载时仍会放大摆动，20 次速度迭代也未解决，因此未增加求解预算。最终候选连接只抵抗相对速度（correctionFactor=0），保留有限力、扭矩和断裂参考，并以现有接触角阻尼衰减余晃。具体见 [胶层因果对照](../review/evidence/difficulty-r1/MOTOR_CONTACT_DIAGNOSIS.md)。有限力、扭矩和位置修正的含义参照 [Box2D 2.4 MotorJoint 定义](https://box2d.org/doc_version_2_4/structb2_motor_joint_def.html)；是否舒服仍以当前安装后端和实际对照为准。

局部木板对照将连接开/关与长度分开：两组均保留相同 1.8 板面缓冲，关组仅在 QA 禁止建立局部连接。初始支撑是明确布置的实验结构，不当作正常开局或玩家胜率。

- 双支点、260 板：两组都承接后续两件并稳固；连接组下层最大漂移 0.967 → 0.541 世界单位，右支点峰值角速度 0.118 → 0.0465 rad/s。
- 单支点、x=55 合理偏载：关闭连接翻倒，开启后板与后续两件全部确认；板峰值倾角 58.7° → 1.205°。
- 双支点、x=110 偏载：等质量 225 板两组失败，260 板两组成功，说明宽度和局部连接各有独立作用。
- 单支点、x=125 严重偏载：两组仍失败，连接真实断裂。连接组会向下层传力，不能宣称无条件保护下层。记录见 [8 个局部对照](../review/evidence/difficulty-r1/FINAL_BOARD_FIXTURES.json)。
