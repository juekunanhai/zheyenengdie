## 最小方案与复杂度判断

复用现有 TowerWorld、StackGameController、PlayView、GameAudio；物体形状、已认可的 difficulty-r1 难度与 R13 结算视觉保持。只增加一个纯事故上下文，集中保存一次事故中必须固定的边界、观察集合及去重结果。它不负责星数、状态流转、计时、导演或随机抽取。

需要这一个上下文，是因为逻辑边界、计划镜头范围和旧塔倒塌计数必须在同一事故生命周期内保持一致；若散落在各镜头/掉落回调中，动画和重复事件容易改变门槛或重复扣星。当前不需要通用事件总线、结构力学求解器、ECS、完整 TowerRisk、导演、道具或检查点。

## 当前规则来源

产品规则以原输入 `docs/zhynd_codex_handoff/SPEC.md` 的 **2026-09-13-R6** 为准，特别是第 3.2、4.4–4.5、6.1–6.5、13.4、28 和 29 节。后续确认的 [1.5 秒观察](PLACEMENT_WAIT_R1.md)、[基础难度](DIFFICULTY_R1.md) 保持；历史设计图不能覆盖规则。

- 初始 3 星；同一有效普通事故最多扣 1 星，当前星数降至 0 立即锁定失败。数量型倒塌无视剩余星数直接失败。
- 首次有效掉落或持续倒塌趋势建立事故；趋势恢复但没有实际掉落时不扣星。
- 同一事故未结束时，继续统计不同物体的实际掉落。没有固定若干秒后自动拆分事故的规则。
- 剩余活动结构恢复稳定且无持续待处理掉落后才能关闭事故。普通观察首次接触后最多 1.5 秒，事故不受这个上限强制出物；普通轻晃不能无依据无限延长为事故。
- 正常 1 倍逻辑边界、计划观察范围、成员集合、N/K 和已确认塔顶参考在事故内固定，不跟随演出缩放、平移或震动。
- 逻辑区域左、右、下方以整个碰撞轮廓越界判掉落；顶部越界不算。稳定旧塔被镜头移出屏幕不算掉落；屏外旧塔须有真正脱离主支撑且持续下坠的证据。
- 失效物体须在碰撞求解前退出后续影响。当前实现随后在 `afterPhysics` 安全阶段将失效节点设为 `active=false`，停止其原生刚体模拟与显示；不在接触回调内立即 `destroy`。诊断记录保留至本局场景卸载时统一销毁，不再参与支撑、成绩、再次救场、声音或计数。
- 超时出下一件不等于稳定成功；尚未成功放置的较早释放物体也不进入旧塔倒塌集合。

## 冻结集合与数量门槛

```text
S = 与计划观察范围相交、已成功放置、仍有效的塔体集合
N = S 的唯一 objectId 数量
N < 3 时 K = null，禁用数量型失败
否则 K = min(6, max(3, ceil(0.60 × N)))
L = 本事故已确认掉落的唯一 objectId 集合
当 |L ∩ S| >= K 时，数量型倒塌失败
```

N 为 3、5、8、10 时，K 分别为 3、3、5、6。本次未成功放置的新落物可以触发普通扣星，但不能凑旧塔数量；后续稳定的物体不补进 S，损失物体不缩减 N。

`assets/batch1/incident-state.ts` 的 `Incident` 只处理该纯规则：构造时复制边界与成员，`recordLoss()` 去重并返回 `firstLoss/duplicate/collapse`，由控制器消费 `firstLoss` 扣星。调用者负责从真实物理状态筛出有效、已成功放置且与观察范围相交的成员。

## 当前实现参数与调优边界

正常视野约可见 3–5 件时计划缩放 0.75，拉远 0.35 秒；剩余结构稳定 0.6 秒后以 0.45 秒恢复。恢复期间保留同一事故，若再次下坠则暂停镜头恢复，继续原来的扣星保护与累计；失败演出 1.2 秒。HUD 不缩放；在手物、规划剩余时间与 NEXT 恢复后继续，事故期间不强制出物。

深层辅助保留 SPEC 的 1–3 屏 smoothstep 角阻尼曲线，只用于仍有有效主支撑、位于正常视区下方的旧体。当前新增角阻尼上限 8，随时间以响应系数 8 平滑；支撑接触宽限 0.12 秒，持续下坠阈值为物理速度低于 -0.75m/s 达 0.12 秒。离开支撑后辅助关闭。定向实测已验证深度曲线、开关对照与脱离失效，不等于任意结构的长期难度标定；没有改变质量、搬动物体、扶正或建立隐形底托。

音频按用户“所有的音效先不要用电子音，去网站上搜集一些音效，然后使用”的授权，已导入 [A3 自然拟音](AUDIO_DELIVERY.md)：保留 12 项实录材质声，替换 6 项操作/结束声，新增掉星与陶瓷 4 项，共 22 MP3。实际 AudioSource 的启动、结束、强碰撞优先、暂停/静音及结束换场已通过；21 项当前使用声音覆盖，stable 只预留。采用状态不等于用户主观试听通过；BGM 不随本轮接入。
