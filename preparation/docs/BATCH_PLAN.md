## 1B 的反例验收

- 普通观察首次接触后最多 1.5 秒；事故持续超过该时长仍不生成下一件，处理结束且允许继续后只生成一次。
- 同一事故未到 K 最多扣一星；达到 K 即使还有星也结束。
- 无恢复星介入时，第三次普通事故使 1 星变 0，立即结束；不能等第四次。
- 同一 objectId 重复越界只计一次；当前未成功放置的新物体不进入旧塔倒塌集合。
- N/K 和集合在事故开始固定；正常视区只能看到约 3–5 件时拉远演出，计数不因动画改变，HUD 保持大小。
- 镜头上移后屏外旧支撑物仍承重，不因屏幕位置扣星；真正脱离支撑并持续下落才失效。
- 落物在同一物理步越界并接触下方塔时，必须在求解前禁用影响；核实物理后端 API 时序，不能下帧删除冒充解决。
- 深层歪放物体保留偏心和倾角；辅助角阻尼随深度平滑增强，自由下落不被托住。辅助开/关采用相同初始结构与投放序列对照。
- 抽取 seed 用于复现，不承诺不同平台物理逐帧一致。
