# 镜头、落地与首页动效 R1

2026-09-15，承接用户对事故缩放、落地手感和静态首页的反馈。本轮为 Batch 1C 基础表现修复，不推进 Batch 2。当前文档在表现规则上补充原 SPEC 第 11 节；原始交接文件和此前验收记录保留历史含义。

## 原因与最小方案

旧 PlayWorld 仅做平面缩放，景观与云不响应；真实接触仅播放音频，Sprite 始终刚性复制物理姿态。首页此前只有缓慢云移动和按钮按压，主体、拖鞋、木牌和飞行物不动。

最小方案：沿用 Cocos 2D 节点、现有物理回调和已确认美术，统一镜头距离表现，加短暂的接触点变形/尘点，首页按分层做少量错相运动。是否需要更复杂方案：不需要新 3D 摄像机、粒子系统、动画依赖、物理弹性或完整动画状态机。落地动效单独一个模块，是因为瞬态生命周期、接触锚点与特效限流有独立职责；不引入通用框架。

## 镜头

- 事故条件、目标倍率 0.75、冻结观察集合及死亡边界保持。光学中心仍是 SafeArea 中心，转成 Canvas 坐标传给背景。
- 使用距离而非缩放值插值：D=1/z；在 0.35 秒拉远，0.45 秒恢复。重复事故从当前距离继续，不跳回初始值。
- 分层倍率为 `1 / (1 + (D - 1) * depth)`。塔与近地面 depth=1，城市0.08，云景0.16，太空0.07，三片飘云分别0.62/0.45/0.30。城市按远景处理，0.75 倍后移时城市倍率约0.974；在375像素视口中新露出的单侧约5像素，减少边缘镜像建筑的可辨识重复。近地面与飘云保留更明显的运动，形成后移感。边缘仍使用原图镜像延展，并非新增完整宽幅背景。
- 镜头高度仍读取平滑后的实际视点，背景随叠高变化。HUD、NEXT、按钮不参与世界缩放。
- 正常倍率保留原构图。缩远新露出的边缘用同图对应边缘像素镜像延展，上方仍使用已有清空天空带；不横向拉伸建筑。边缘重复是否可接受需实际画面检查，不把矩形覆盖检查当美术验收。

## 落地

- 使用原生 BEGIN_CONTACT 的真实接触点与法线；立即复制 manifold 数据。点速度包含旋转，按 Creator 3.8.8 的 PTM32 转成碰撞音效使用的速度单位。
- 只对未成功放置、真实向承托面靠近的落入物体做压缩。侧擦、分离、无接触不触发。凹形的多个原生接触仍逐一检查有效落地，音频保持物体对去重。
- Sprite 围绕实际接触点在物体本地坐标中缩放，持续0.32秒。篮球/纸箱等柔软材质较明显，冰箱等硬物较轻，短回弹后归位。不改变碰撞体、节点物理尺度、刚体速度、摩擦、胶接或距离辅助。
- 尘点在接触位置向两侧散开，强硬物落地增加短环。每个物体0.48秒防重复，整体两次尘点至少间隔0.09秒，同时最多4组/12张Sprite，0.38秒清理。
- 失效/禁用支撑取消表现，暂停冻结，换场释放。不新增声音，不改变原有倒塌尾声。
- 原始特效图带邻图残片，故补齐两张完整正式图。运行纹理分别256×256和256×128；原图、提示词、透明清理脚本与哈希见 [素材清单](../design/camera-impact-r1/ART_MANIFEST.json)。

- 飘云另换为完整轮廓的512×192正式图，避免旧HUD云图底部裁口随漂移变得明显。只替换HUD引用，首页原图保留；来源见 [背景云清单](../design/camera-impact-r1/BACKGROUND_CLOUD_MANIFEST.json)。

## 首页（动作已由首页表情 R1 覆盖）

以下保留首轮方案记录。用户随后明确反对物体散开漂浮，最新动作及实现以 [HOME_EXPRESSION_R1.md](HOME_EXPRESSION_R1.md) 为准；本文件的镜头与落地规则保持。

- 保留认可的 R10.1 构图与资源。箱子/马桶/鸭子在现有图中是一个整体，沿其真实画稿底部接地点做±0.6°呼吸摇摆与0.8%高度呼吸；没有将贴图重新抠成独立角色。
- 点击主物群触发0.55秒小幅衰减摇摆。前后拖鞋错相3–5设计单位浮动，木牌绕挂点摆动且文字一起走，Logo轻呼吸，飞艇/飞机以不同周期漂移。
- 开始按钮每6.2秒有一次0.9秒、1.5%的轻脉冲；触摸按下保持0.96，设置按钮保持静态便于寻找。原入口和首页音乐保留。
- 动作从每次布局计算的基准位置出发，不累积偏移；隐藏/禁用停止并清理交互动画。
