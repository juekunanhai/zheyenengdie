# 首页角色表情 R1

2026-09-15，承接用户“表情要动起来，不要全部分散着到处飘”的修正。范围仅为首页角色表现，覆盖 CAMERA_IMPACT_HOME_R1.md 的首页动作规则；该轮镜头、落地及此前距离辅助保持。

## 原因与方案

箱子、马桶和鸭子画在同一张已认可主角图里。对整张图呼吸、摇摆，再让拖鞋独立浮动，只会产生整体晃动，不能表达角色在眨眼或相互抓握。

最小方案：保持原图和摆放，用四张眼部材质补片、两张手臂帧加一个动作时间表。是否需要更复杂方案：不需要骨骼、网格变形、新动画状态机或依赖。沿用已有 HomePresentation 和 Cocos Sprite，源像素配准解决局部替换和接触关系即可；不扩展到游戏中每种物品的新动作系统。

## 行为

- 主角、两只拖鞋、木牌、Logo 保持原位及原角度，删除整体呼吸、摇摆和独立漂浮。云和飞行物继续缓慢移动；开始按钮保留短促邀请和按压。
- 鸭子、箱子和两只拖鞋以错开的时刻短暂闭眼，通常持续0.13秒。鸭子偶尔连眨两下。闭眼素材完整覆盖原眼部，不用半透明眼睛交叉淡化。
- 马桶原图是笑眼，动作开始时短暂睁眼；小手从肩部抬起的姿势向箱沿伸出。0.62–1.12秒握持，箱子以两次闭眼回应；随后松手收回，重新露出原来的笑眼。
- 第一轮在进入首页2.8秒后开始，整段1.65秒，结束后安静7.4秒再来一次。点击主角提前触发下一次；动作中连续点击不打断、不排队、不多生手臂。
- 后台或组件禁用立即清除临时表情和手臂，隐藏期间时钟停止；恢复后重新等候1.2秒。场景销毁由节点层级释放，按钮原逻辑保留。

## 配准与美术来源

原主角1024×1536，拖鞋340×257。局部眼睛矩形见 [表情清单](../design/home-expression-r1/face/manifest.json)。补片作为对应图的子节点，以源图尺寸换算显示位置与宽高，不能用来改变物理尺寸。

手臂两帧291×276，肩部在手图左上坐标(249.9,39.9)，对应主角(423.9,800.9)。该锚点固定，仅转动−12°到0°；零度时手指(88,231)对应主角箱沿(262,992)，整个握持阶段保持零度与完全不透明。两帧手指有张开/扣住区别，整件角色不位移来伪造接触。

六张新增PNG由内置 image_gen 以原素材为参考生成，再用用户授权的本地流程配准、提取透明和局部补片。原图未覆盖、未裁切拆成新的漂浮部件；保留完整生成源图、实际提示词、处理脚本和哈希。
