# Batch 3 implementation

2026-09-18。继续在不构建、不启动项目的约束下接入图鉴与普通战绩分享的源码闭环。截图、录屏和日志属于本地过程证据，本轮不纳入提交。

## 已接入

- `CollectionLedger` 保存 24 件物体和 6 个道具的发现状态，物体第一次出现在 CURRENT、道具第一次从三选一领取时解锁；撤销、检查点恢复和重新进入结算不会回退发现状态。
- `PlayerProgress` 通过独立的本地存储边界保存发现列表和最高高度，数据校验拒绝重复、未知条目和非法高度；后续可替换为云端同步，不把平台 API 放入玩法层。
- Home 增加运行时图鉴入口。图鉴分为物体/道具两个列表，锁定项显示 `???`，已解锁项可以进入独立详情页，详情包含名称、重量感、稳定性、性格和描述。页面使用安全区内的运行时节点，不修改现有场景结构。
- Result 增加真实的“图鉴新增”提示和普通“分享战绩”入口。分享通过 `ShareAdapter`，微信使用普通转发 query，Web 使用平台原生分享能力；不包含每日挑战、挑战榜或分享奖励，平台不支持时返回可继续结算的降级状态。
- `runResult` 传递真实 runId、最高高度、新纪录和本局首次发现条目，未用示例值填充。
