# 原始输入与生成素材原图

本目录用于新电脑恢复开发、重新处理美术和追溯设计来源。内容均为复制，原电脑上的原文件未移动或修改。

- `docs/`：产品 SPEC、开发交接、跨平台规则与历史视觉参考。
- `art-source/`：用户提供的完整正式美术素材包，包括 `00_DOCS`、`01_VISUAL_REFERENCE` 和 `02_ASSETS`。历史设计参考不自动成为正式运行素材。
- `generated-images/`：工程文本（包含历史记录）明确引用的生成图片原文件，只收集可追溯的相关文件，没有复制整个 Codex 用户目录。
- `SOURCE_INDEX.json`：每个源文件的旧来源、仓库相对路径、字节数和 SHA256；生成图包含引用位置，已在工程中存在相同字节副本的文件亦列明。

当前游戏读取 `assets/` 中已采用的素材，运行与 Creator 构建不依赖旧电脑的绝对路径。旧路径只保留为来源记录。不要为了复用旧路径移动仓库或重建旧用户目录；需要重新处理素材时，从本目录查找对应仓库相对路径。历史脚本和验收记录中的绝对路径、脚本哈希没有被改写，历史报告不代表新电脑已重新验收。

克隆后的工具安装、启动和静态完整性检查以工程根的恢复开发说明为准。
